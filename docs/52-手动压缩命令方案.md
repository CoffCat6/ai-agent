# 52 - /compact 手动压缩命令（LLM 摘要式上下文压缩）

| | |
|---|---|
| **状态** | **已实施（2026-11-15）**：`/compact [重点]` 全链路（AIAgent → Controller → VM 内置命令 → InputConsole） |
| **背景** | 上下文压缩此前只有**纯截断**（`TokenEstimator::compressToFit`，自动触发完备：发送前/窗口变更/恢复会话/每轮请求前），被截断的旧历史原文丢失；无手动触发入口 |
| **不做** | LaTeX/mermaid 渲染（另行评估）；压缩结果持久化（见下） |

## 1. 语义

`/compact [重点]` 在输入框触发（斜杠补全可见，内置命令表 v1 只有 compact）：

1. **锚定**：从最后一个 user 消息起的连续后缀**原文保留**（tool_call 配对契约，与
   `compressToFit` 同一锚定规则）；其前的历史（跳过首条 system）交 LLM 摘要。
2. **摘要调用**：复用**当前会话的 `m_llmService`**（用户预期"用当前模型压缩"）；
   异步一次性连接（EpisodicService 范式）+ 90s 超时；转录单条截 8000 字符、
   总量 60k 字符上限（摘要请求自身也要装得进窗口）；用户 `[重点]` 参数注入
   "Additional focus"。
3. **替换**：`[原 system, 摘要 system 消息, 最近后缀...]`——摘要消息 content 以
   **`[Context compressed:` 前缀**开头（分类器标记复用：contextComposition/TopBar
   "已压缩"角标/trace 全部自然记账），后接摘要正文（≤8000 字符）。
4. **记账**：`m_omittedContextMessages += omitted; ++m_compressionCount;`
   `notifyTokens()` + `appendTraceNode("context", "Manual compaction (/compact): ...")`。
5. **不持久化**：与自动压缩同一契约——消息表保留全量历史，压缩结果仅内存态
   （resume/换窗口时 `restoreFullHistoryIfAvailable` 依赖它）；因此 /compact 是
   **会话内即时操作**，重启后历史全量恢复（超预算会再自动压缩，走截断）。
6. **失败明报**：无脚本响应/超时/空摘要 → `compactFinished(false, 原因)`
   （AgentViewModel 转 errorOccurred toast），上下文原样不动——**没有静默截断
   兜底**（用户要的是摘要，给有损截断是撒谎）。
7. **守卫**：任务运行中（`m_active`）或压缩进行中（`m_compacting`）返回 false
   （AgentVM 提示"任务运行中"）；历史不足（无 user 锚点/无可摘要段）报"没有
   足够的历史可压缩"。

## 2. 实施坑（勿回退）

- **一次性连接必须先于 `chatComplete()` 建立**：FakeAIService 与部分 provider
  在调用栈内**同步** emit `responseReady`——后连接永远收不到摘要（单测捕获）。
  EpisodicService 的顺序即如此。
- `onLLMResponse` 开头 `if (!m_active) return`——compact 期间任务 idle，主链
  自动忽略摘要响应，与专用一次性连接无竞争。

## 3. 内置命令管道（SlashCommand 之外的缺失环节补齐）

`SlashCommand::expand` 只展开用户模板命令，未知 `/...` 原样透传给模型——内置
命令此前不存在。本次补齐拦截点：

- `AgentViewModel::handleBuiltinCommand(text)`（Q_INVOKABLE）：内置命令表 v1
  仅 `/compact`；命中即消费（返回 true，InputConsole 清空输入不再发送），
  未命中返回 false 走原链路。
- `InputConsole::updateSlash`：内置命令候选**排最前**（`builtin: true`），
  与用户模板/MCP prompts 合并；`applySlash` 通用替换逻辑自然适用（插入
  `/compact ` 供追加参数）。
- 提交处（InputConsole 发送链）在 `startTaskWithSkills` **之前**调
  `handleBuiltinCommand`——`/compact` 永远不会作为聊天文本发给模型。
- 后续内置命令（/new 等）只需在表与 handleBuiltinCommand 各加一行。

## 4. 测试

- `test_agent`：`manualCompactSummarizesHistory`（形态/前缀/后缀保留/trace/记账）、
  `manualCompactFailsWithoutScript`（失败路径 + 上下文原样）、
  `manualCompactRejectsWhenBusy`（busy 守卫）——**181 用例全绿**
  （1 个基线既有失败 subagentEvidence 与本功能无关）。
- `test_chat_workflows` 的 slash 补全用例在本机有既知环境性失败（SEGFAULT
  基线），内置命令补全的可视化验证随 Windows 侧回归覆盖。

## 5. 明确不做

- 压缩结果持久化（破坏全量恢复契约）；
- 摘要式压缩的自动触发（自动路径仍为截断——摘要请求有成本与延迟，超预算
  场景每轮都摘要不现实；用户可用 /compact 手动触发）；
- LaTeX/mermaid 渲染（另行评估，与本命令无关）。
