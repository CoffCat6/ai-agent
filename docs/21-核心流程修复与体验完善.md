# 核心流程修复与体验完善

本批按功能与用户体验审查的优先级，完成核心对话修复和第一组日常使用改进。

## 已完成

| 范围 | 行为与验收点 |
| --- | --- |
| 文本附件 | 输入区保留 `kind=file`，附件内容实际进入模型请求；请求未接受时保留正文和附件 |
| 编辑重发 | 统一回退末轮，数据库消息与轨迹在事务中截断，再同步内存；保留已有附件；数据库失败时原内容不变 |
| 重新生成 | 复用末轮回退，同时移除持久化旧轨迹，避免重开会话后旧答案复现；重新生成前检查配额 |
| 多标签草稿 | 每个标签独立保存正文和附件，切换、关闭其他标签时恢复正确内容；当前为进程内保存 |
| 多标签模型 | 聊天区模型与思考强度仅影响当前标签；设置中的活动配置用作新会话默认；执行中禁止切换，服务配置保持不变 |
| 模型配置更新 | 运行任务保持原配置；下一轮使用最新的对应配置；不同标签的模型选择保持独立 |
| 并行审批 | 请求排队，按唯一确认 ID 路由到来源控制器；展示来源会话与待处理数量；停止或关闭标签后清理失效请求 |
| 命令停止 | 取消标记按调用持有，排队期间停止也不会启动命令；不同标签的 shell 调用互不消费对方的取消标记 |
| 本地模式 | 知识库是否可用按每个任务的模型判断；搜索与 MCP 网络工具在仅本地模式禁用，审批后再次校验工具可用性 |
| 会话恢复 | 轨迹持久化保留附件与回答使用的模型；新增字段通过幂等迁移补齐 |
| 首次使用 | 未配置时提供“配置模型”入口；明确打开模型设置时不再被上次设置分类覆盖 |
| 错误恢复 | 最后一轮错误提供重试、模型设置和复制；重试会重新执行本轮，不是从失败的工具步骤断点续跑 |
| 历史管理 | 会话操作菜单支持置顶、归档、恢复；“包含已归档”同时作用于侧栏与历史搜索 |
| 窗口与无障碍 | 设置窗口跟随可用空间；弹窗的无障碍名称挂接到实际内容 Item |
| 文案 | 同步中英文翻译与用户手册，移除演示模式等过时说明 |

## 验证

新增 `test_chat_workflows`，加载真实 InputConsole、ToolConfirmDialog 和主窗口，使用录制请求的本地测试服务，不调用外部模型。

- 真实输入组件发送文本附件，并保留被拒绝的输入。
- 切换标签与关闭标签恢复各自草稿及附件。
- 编辑后请求内容、持久化消息及恢复的轨迹一致，附件保留。
- 注入数据库写入失败，验证原上下文与轨迹不变。
- 两个会话同时等待审批，验证准确路由、队列推进及停止后的失效处理。
- 更新默认配置、切换标签模型时，正在运行的任务不变。
- 归档搜索同时覆盖短词 LIKE 和全文索引路径；重开数据库仍保留置顶与归档状态。
- 主窗口在 900×600 下加载，检查 QML 运行时告警。
- 本地模式下，知识库门控使用各自任务模型。
- 占满工作线程，排队后停止 shell，验证不会启动命令或写入文件。
