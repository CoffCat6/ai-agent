## 2. 第三阶段缺口清单（G = Gap，延续第二阶段编号）

### G9【P1】语言切换仍无实际效果（英文翻译缺失）

- **证据**：源语言即中文，仅 `translations/nexus_ai_zh_CN.ts`（恒等翻译，178 条 0 unfinished）；
  无 `nexus_ai_en.ts`，选 English 时 I18nManager 对 target=="en" 直接跳过加载
  （`I18nManager.cpp` applyLocale 分支），界面停留在中文源文案。
- **影响**：设置中心的界面语言功能形同虚设；G4 的修复只完成了"链路"，没完成"内容"。
- **附注**：Batch 21 部署验收时修复了 `QTranslator::load` 重载陷阱（QString 首参重载把
  locale 当 filename，恒失败）——中文翻译链路已实证打通（日志 `Loaded translation: "zh-CN"`），
  英文补齐后切换功能即可整体生效。
- **建议**：Batch 24。

### G10【P2】主题只有深/浅两档，无"跟随系统"

- **证据**：`ThemeManager::registerPreferences` 的 themeMode 枚举仅 `{"dark","light"}`，
  默认 dark；无系统主题监听。
- **影响**：Windows 深浅色切换后应用不跟随；语言已有「跟随系统」（auto），主题不对称。
- **建议**：Batch 28。

### G11【P2】知识库嵌入端点硬编码本机

- **证据**：全仓 grep 无 embeddingBaseUrl/embedding/baseUrl（2026-09-12 实测）；嵌入模型
  名可配（Batch 8 FEAT-801）但 Ollama 地址固定本机 11434。
- **影响**：Ollama 部署在其它主机/端口时，向量嵌入与知识库导入直接不可用。Batch 4-8 按
  用户指示跳过（有档），第三阶段恢复实施。
- **建议**：Batch 25。

### G12【P3】日志面板会话级，跨重启历史丢失

- **证据**：日志面板为"追加式会话语义"（四轮修复定型），重启后清空；旧日志仅在
  `%LOCALAPPDATA%/NexusAI/NexusAI/logs/` 文件中。
- **建议**：启动时回填最近 N KB 日志文件入缓冲（环形去重），小批；可与任意批搭车。

## 7. 执行纪律（沿用 docs/7 第 7 节，第三阶段补充三则）

1. **PowerShell 原生命令**：stderr 告警在 `$ErrorActionPreference=Stop` 下会升格为终止
   错误——脚本一律按 `$LASTEXITCODE` 判成败（Batch 21 实录）。
2. **QSettings Windows 原生格式的 bool 是 REG_SZ 字符串**：读取侧必须按注册元数据归一
   类型，QML 严格比较才可靠（设置中心实录，PreferenceStore::coerce 为既定模式）。
3. **QTranslator::load 必须用 QLocale 重载**：QString 首参重载把 locale 当 filename，
   恒失败（Batch 21 实录）。
