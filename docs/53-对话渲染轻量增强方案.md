## 1. LaTeX 近似（core/utils/MathText.h，header-only 纯函数）

`MathText::render(input)` 识别四种公式 span：`$$…$$`（display，前后加换行）、
`\[…\]`、`$…$`、`\(…\)`，把 span 内容转为 Unicode 数学文本：

- **覆盖**：希腊字母（大小写 ~34 个）、常用运算/关系/箭头/集合符号（~45 个）、
  上下标（数字/字母逐字符映射，`x^2`→x²、`y_1`→y₁、`2^{10}`→2¹⁰）、
  `\frac{a}{b}`→(a)/(b)、`\sqrt[n]{x}`→ⁿ√(x)、`\text/\mathrm/\mathbf` 去壳、
  `\left/\right` 剥离、`&`→列分隔、`\\`→换行、`\begin{…}/\end{…}` 剥壳。
- **守卫**（防破坏）：
  - `$…$` 需含数学特征（`\` 命令 / `^` / `_` / `{} / =`）——"the price is
    $5 and $10" 原样保留；
  - 反引号行内代码整段跳过；
  - 未识别的 `\command` **原样保留**（绝不静默改写）；
  - 组内命令先转换再尝试脚本映射（`^\alpha` → ^α；映射不到的字符保留）。
- **已知坑**（勿回退）：输出含非 Latin-1 字符的字符串字面量必须用
  `QStringLiteral`，`QLatin1String("√(")` 会把 √ 拆成 UTF-8 字节序列（单测
  捕获过）。

## 2. 接线

- `AgentViewModel::renderMath`（Q_INVOKABLE static）转发到 `MathText::render`；
- `AssistantMessage.qml`：单 TextEdit 路径（`mdText.text`）与分段路径的
  text/heading 段在渲染前转换；**围栏代码段不转换**（分段先切围栏）；
- `CodeBlock.qml`：`languageLabel === "mermaid"` 时 header 出现
  「复制源码并在 mermaid.live 打开预览」按钮（copy 源码 + `Qt.openUrlExternally`
  打开 mermaid.live/edit）——图形渲染交给浏览器，应用内保留源码与高亮。

## 3. 明确不做

- QtWebEngine/KaTeX/mermaid.js（体积与沙箱代价，见决策行）；
- 矩阵等复杂环境的排版（仅剥壳平铺，`\begin{pmatrix}…` 转换后可读性有限——
  该场景建议模型输出代码块）；
- display 公式的居中/编号（Unicode 文本路径无排版能力）。
