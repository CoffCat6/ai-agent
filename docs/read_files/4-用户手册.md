## 1. 界面总览

启动后看到三栏布局(`src/ui/main.qml:22-111`):

- **左侧栏**:新会话按钮 + 历史会话列表;底部有"审计日志"和"设置"两个入口。可通过左边缘的把手收起/展开(快捷键 `Ctrl+[`)。
- **中间聊天区**:顶部是状态栏(显示当前状态文字,如"思考中");中间是**思考过程时间线**;底部是输入框,输入框下方显示当前使用的模型。
- **右侧上下文面板**:知识库管理 + Token 用量。可通过右边缘把手收起/展开(`Ctrl+B`)。左右栏宽度都可以拖动中间分隔条调整,并会记住你的偏好。

### 全局快捷键

## 2. 第一次使用

首次启动时还没有配置任何 AI 模型,应用运行在**内置演示模式**:它会用一段预置脚本模拟完整的"思考 → 调用工具 → 回答"过程,让你先熟悉界面。

![截图占位:演示模式下的模拟轨迹]

要真正开始使用,请先配置模型(下一节);配置完成后,演示模式自动让位于真实管线。

## 3. 配置 AI 模型

1. 按 `Ctrl+,` 打开设置。
2. 在"模型配置"区新建一个 **profile(配置方案)**:选择类型——OpenAI 兼容 / Claude / Ollama 本地。
3. 按下表填写(默认值已按类型预填,通常只需改 Key 和模型名):

| 类型 | 需要填写 | 说明 |
|---|---|---|
| OpenAI 兼容 | API Key、模型名 | 兼容各类 OpenAI 格式的服务/代理 |
| Claude | API Key、模型名 | Anthropic 官方或兼容端点 |
| Ollama 本地 | 模型名 | 需要本机已安装并运行 Ollama;无需 Key |

4. 保存后,点击输入框下方的**模型选择器**,选中刚配置的方案。
5. 可用设置页的"连接测试"按钮验证是否连通。

![截图占位:设置对话框中的 profile 编辑]

- 可以创建多个 profile(比如一个云端、一个本地),随时用模型选择器秒切。
- API Key 在 Windows 上按用户加密保存,不会明文落盘。
- 每个会话消耗的上下文长度可在设置中调整(contextTokens),一般保持默认即可。

## 4. 发起对话

1. 在底部输入框输入问题,按 `Enter` 发送。
2. 时间线上会依次出现:**你的消息 → 思考 → (工具调用与结果) → 回答**。"思考/工具"这些中间步骤默认展开,点击右上角的"**折叠过程**"按钮可以只看最终回答(按钮会显示被折叠的步骤数)。
3. 回答较长时往回滚动阅读,自动跟随会暂停;点右下角的**回到底部**按钮恢复跟随。
4. 回答不满意或想中途打断:点击输入框右侧的**停止按钮**,已完成的部分会保留在时间线上。
5. 点击左栏"**新会话**"(`AgentVM.newChat`)开始一段全新对话;互不干扰。

![截图占位:一次带工具调用的完整轨迹]

## 5. 工具调用与安全审批

NexusAI 的模型可以调用本地工具来完成你的请求。安全规则:

- **只读类**(读文件、列目录、搜索知识库):自动执行,无需确认;但只能在允许的目录里活动。
- **写入/命令类**(写文件、执行命令):每次都会弹出**确认对话框**,显示工具名和完整参数,你点击"允许"才会执行;点"拒绝"则模型会改用别的方案。
- **危险工具**(如递归删除):系统层面永久禁用,模型根本"看不见"它们。

![截图占位:工具确认对话框]

设置里有一个"**允许全盘读取**"开关,默认关闭——保持关闭时,Agent 只能读取你的文档/下载/桌面等目录,读不到其他个人文件。除非你明确知道自己在做什么,不建议打开。

所有工具活动(谁、何时、执行了什么、成功与否)都记录在**审计日志**里(`Ctrl+L` 查看)。

![截图占位:审计日志对话框]

## 6. 知识库(让 AI 回答你的文档)

把你自己的文档导入知识库后,提问相关内容时模型会自动检索引用:

1. 在右侧面板点击**导入文档**按钮,选择 `.txt / .md / .json / .csv / .log` 文本文件。
2. 导入会分块并向量化,大文档需要几秒到几十秒(面板显示"导入中…")。
3. 之后直接在聊天里问,例如"根据知识库里的 xx,……",模型会检索相关段落作答。
4. 文档条目右侧可以:**查看分块**(了解它被切成了哪些段)、**重新嵌入**(见下方降级说明)、**删除**单个文档;也可一键清空整个知识库。

![截图占位:知识库面板与文档详情]

**关于"降级"角标**:知识库检索依赖 Ollama 嵌入服务;如果导入时 Ollama 没在运行,文档会自动降级为本地简化检索(可用但质量有限,条目上会标"降级")。装好/恢复 Ollama 后,点该文档的"重新嵌入"即可升级为高质量检索。

注意:知识库内容存在应用内部,不是磁盘上的普通文件——问知识库相关问题时不需要也不应该让 Agent 去磁盘上找文件。文档内容会作为检索结果发给当前配置的模型服务,介意隐私请不要导入敏感文档(面板上也有这条提示)。

## 7. 会话管理

- 左侧栏列出最近的会话(当前会话加粗);点击任意会话**恢复完整时间线**(包括当时的思考与工具过程)。
- 会话条目支持**重命名**(双击标题)与**删除**(删除会连同其全部消息一起清除)。
- 会话数据保存在本机 SQLite 数据库中,重启应用不丢。

## 8. 查看审计日志

`Ctrl+L` 或左栏底部按钮打开。按时间倒序显示每次工具相关事件:执行、批准、拒绝、被沙箱拦截、未知工具,含参数摘要与结果。排查"它刚才到底干了什么"就看这里。

## 9. 常见问题(FAQ)

**Q:发消息提示"No LLM service configured"?**
还没有配置模型,或没有选中任何 profile。见 §3。

**Q:回答很慢?**
本地模型(Ollama)生成速度取决于硬件,属正常;云端模型慢多见于网络/代理问题。每轮请求有超时上限,失败会有明确报错。

**Q:Token 用量数字和官方后台对不上?**
界面显示的是本地估算值(对中文做了专门加权),不是官方精确计数,仅用于把握上下文占用。

**Q:知识库答案质量差 / 答非所问?**
先看文档是否有"降级"角标(§6 重新嵌入);再尝试在提问中明确引用知识库("根据知识库……")。阈值之下宁可说"没有匹配",这是刻意设计。

**Q:模型一直想调用工具,连打招呼都要查知识库?**
应用内置了防重复调用与历史折叠机制,一般会自愈;若某模型持续如此,换模型或新开会话。

**Q:它写的文件在哪?我拒绝了它会怎样?**
写文件默认只允许写到你的用户目录(文档/下载/桌面等),且每次都要你批准。拒绝后模型会收到"用户已拒绝"并调整方案,不会有副作用。

**Q:我的数据都在哪?能备份吗?**
会话在 `%APPDATA%\NexusAI\NexusAI\nexusai_memory.db`,配置在注册表 `HKCU\Software\NexusAI\NexusAI`,日志在 `%APPDATA%\NexusAI\NexusAI\logs`(保留 7 天)。备份方法见部署指南 §7。
