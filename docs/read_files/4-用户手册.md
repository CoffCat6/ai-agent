## 1. 界面总览

启动后看到三栏布局(`src/ui/main.qml:22-111`):

- **左侧栏**:新会话按钮 + 历史会话列表;底部有"审计日志"和"设置"两个入口。可通过**顶栏最左侧的侧栏按钮**收起/展开(快捷键 `Ctrl+[`);图标会随状态变化——展开时显示"填实的侧栏 + 向内箭头"(点它收起),收起后显示"空侧栏 + 向外箭头"(点它展开)。
- **中间聊天区**:顶部是状态栏(显示当前状态文字,如"思考中");中间是**思考过程时间线**;底部是输入框,输入框下方显示当前使用的模型。
- **右侧上下文面板**:知识库管理 + Token 用量。可通过**顶栏右侧的面板按钮**收起/展开(`Ctrl+B`);图标与左侧侧栏按钮同一套样式(窗口轮廓 + 面板分隔线 + 面板填实/留空 + 指向箭头),只是方向镜像到右边。左右栏宽度都可以拖动中间分隔条调整,并会记住你的偏好。
- **日志面板**:侧栏入口打开,按级别/分类/关键词筛选实时日志;重启后可见上次会话的历史日志(带"历史"标记)。

## 2. 第一次使用

首次启动时点击聊天空白页的“配置模型”，填写服务地址、密钥和模型名，完成连接测试后启用。未配置模型时发送不会清空输入，可以配置好后继续发送。

## 3. 配置 AI 模型

1. 按 `Ctrl+,` 打开设置。
2. 在"模型配置"区新建一个 **profile(配置方案)**:选择类型——OpenAI 兼容 / Claude / Ollama 本地。
3. 按下表填写(默认值已按类型预填,通常只需改 Key 和模型名):

| 类型 | 需要填写 | 说明 |
|---|---|---|
| OpenAI 兼容 | API Key、模型名 | 兼容各类 OpenAI 格式的服务/代理 |
| Claude | API Key、模型名 | Anthropic 官方或兼容端点 |
| Ollama 本地 | 模型名 | 需要本机已安装并运行 Ollama;无需 Key |

4. 保存后,点击输入框下方的**模型选择器**,选中刚配置的方案。
5. 可用设置页的"连接测试"按钮验证是否连通。

![截图占位:设置对话框中的 profile 编辑]

- 可以创建多个配置。聊天区的模型选择器只改变当前标签；任务运行时不可切换，其他标签的任务不受影响。设置中启用的配置作为新会话默认。
- API Key 在 Windows 上按用户加密保存,不会明文落盘。
- 每个会话消耗的上下文长度可在设置中调整(contextTokens),一般保持默认即可。

### 联网搜索(web_search)

模型可调用 `web_search` 工具检索实时信息(新闻、价格、天气、文档等),结果回灌给模型作答。

可选三种搜索服务,在设置中心 → 工具 → 联网搜索里切换:

- **DuckDuckGo**(默认):免 API key,装上即可用。国内网络下可能返回人机验证页,此时工具会明确提示"被反爬拦截",需配置代理或换用下面两种;
- **智谱 Web Search**:需 [智谱开放平台](https://bigmodel.cn) 的 API key,按次计费;
- **DeepSeek Search**:需 [DeepSeek 开放平台](https://platform.deepseek.com) 的 API key,与对话 API 共用同一把。

两种付费服务的密钥**分开保存**,切换搜索服务不会串用。

配置完可以用设置里搜索服务下方的**「测试连接」**按钮验证:它会用当前选中的服务真实检索一次(固定查询词),并在按钮旁直接给出结论——连接正常会报「返回 N 条结果」,失败会报出是哪一家失败以及原因(密钥无效/余额不足/限流/被反爬拦截等)。需要密钥的服务在未填 Key 时按钮是禁用的。

对话里每次调用 `web_search`,过程卡片标题右侧会显示一个**来源徽章**(DuckDuckGo / 智谱 / DeepSeek),这样能直接看出这次查询发给了谁;失败时同样显示,便于判断是哪一家出的问题。

- 查询内容会外发到搜索服务,因此每次调用前都会弹**确认对话框**,未确认不外发;
- 开启"仅本地模式"时,`web_search` 会被自动禁用且不暴露给模型。

## 4. 发起对话

1. 在底部输入框输入问题,按 `Enter` 发送。
2. 时间线上会依次出现:**你的消息 → 思考 → (工具调用与结果) → 回答**。"思考/工具"这些中间步骤默认展开,点击右上角的"**折叠过程**"按钮可以只看最终回答(按钮会显示被折叠的步骤数)。
3. 回答较长时往回滚动阅读,自动跟随会暂停;点右下角的**回到底部**按钮恢复跟随。
4. 回答不满意或想中途打断:点击输入框右侧的**停止按钮**,已完成的部分会保留在时间线上。
5. 点击左栏"**新会话**"(`AgentVM.newChat`)开始一段全新对话;互不干扰。

## 5. 工具调用与安全审批

NexusAI 的模型可以调用本地工具来完成你的请求。安全规则:

- **只读类**(读文件、列目录、搜索知识库):自动执行,无需确认;但只能在允许的目录里活动。
- **写入/命令/联网类**(写文件、执行命令、`web_search` 联网搜索):每次都会弹出**确认对话框**,显示工具名和完整参数,你点击"允许"才会执行;点"拒绝"则模型会改用别的方案。
- **危险工具**(如递归删除):系统层面永久禁用,模型根本"看不见"它们。

![截图占位:工具确认对话框]

设置里有一个"**允许全盘读取**"开关,默认关闭——保持关闭时,Agent 只能读取你的文档/下载/桌面等目录,读不到其他个人文件。除非你明确知道自己在做什么,不建议打开。

设置里还有"**仅本地模式**"(localOnlyMode):开启后,所有会外发数据的工具——知识库检索(云端模型时)、`web_search`、以及**全部 MCP 服务器工具**——都会被禁用且不暴露给模型。处理敏感内容时建议开启。

所有工具活动(谁、何时、执行了什么、成功与否)都记录在**审计日志**里(`Ctrl+L` 查看)。

![截图占位:审计日志对话框]

## 6. 知识库(让 AI 回答你的文档)

把你自己的文档导入知识库后,提问相关内容时模型会自动检索引用:

1. 在右侧面板点击**导入文档**按钮,选择 `.txt / .md / .json / .csv / .log / .pdf` 文本文件。
2. 导入会分块并向量化,大文档需要几秒到几十秒(面板显示"导入中…"和嵌入进度)。
3. 重复导入相同内容会自动跳过并提示;文件重名时自动存为 `a (2).txt`,不会覆盖。
4. 之后直接在聊天里问,例如"根据知识库里的 xx,……",模型会检索相关段落作答。
5. 文档条目右侧可以:**查看分块**(了解它被切成了哪些段)、**重新嵌入**(见下方降级说明)、**删除**单个文档;也可一键清空整个知识库。

![截图占位:知识库面板与文档详情]

**关于"降级"角标**:知识库检索依赖 Ollama 嵌入服务;如果导入时 Ollama 没在运行,文档会自动降级为本地简化检索(可用但质量有限,条目上会标"降级")。装好/恢复 Ollama 后,点该文档的"重新嵌入"即可升级为高质量检索。

**重启不丢向量**:文档内容和分块向量都保存在本地数据库;只要文档没改、嵌入模型没换,重启应用后直接从本地向量恢复,不需要联网重新嵌入。在设置中更换嵌入模型会触发一次后台全量重嵌(面板显示进度),期间检索结果可能暂时不全。

注意:知识库内容存在应用内部,不是磁盘上的普通文件——问知识库相关问题时不需要也不应该让 Agent 去磁盘上找文件。文档内容会作为检索结果发给当前配置的模型服务,介意隐私请不要导入敏感文档(面板上也有这条提示)。

## 7. 会话管理

- 左侧栏列出最近的会话(当前会话加粗);点击任意会话**恢复完整时间线**(包括当时的思考与工具过程)。
- 会话条目支持**重命名**(双击标题)与**删除**(删除会连同其全部消息一起清除)。
- 会话数据保存在本机 SQLite 数据库中,重启应用不丢。

- 会话行的操作菜单或右键菜单可**置顶、归档、恢复**。勾选“包含已归档”后，归档会话会出现在列表与搜索结果里。
- 切换标签会恢复该标签的输入草稿和附件；未发送草稿目前不跨应用重启保存。
- 最后一条问题可编辑重发，保留原附件；重新生成会替换原来的末轮回答。回答操作区显示实际使用的模型。
- 多个任务同时需要审批时会依次显示确认框，框内标明来源会话及待处理数量。
- 错误卡提供“重试本轮”“模型设置”和复制入口。重试会重新执行本轮任务。

## 8. 日志与审计

### 8.1 审计日志

`Ctrl+L` 或左栏底部按钮打开。按时间倒序显示每次工具相关事件:执行、批准、拒绝、被沙箱拦截、未知工具,含参数摘要与结果。排查"它刚才到底干了什么"就看这里。

### 8.2 运行日志面板

侧栏入口打开。按级别(DEBUG/INFO/WARN/ERROR)/分类/关键词三维筛选应用运行日志,支持一键复制与打开日志目录。

**跨重启历史**:重启应用后,日志面板会自动回填**上次会话的日志尾部**,这些条目以斜体显示并标注"历史",与本次会话的实时日志视觉区分。回填量有上限(不超过环形缓冲容量的一半),不会挤掉当前会话的新日志,重复条目也会去重。

## 9. 长期记忆(情景记忆)

开启后,NexusAI 会在**每次会话结束时**自动生成一段简短摘要(≤500 字)存入本地;之后**新会话开始时**,系统会检索与当前话题相关的历史摘要并注入上下文,让模型"记得"你之前聊过什么。

- 摘要生成是**异步**的,不会卡住会话结束;
- 注入的历史摘要总量有预算上限(≤1500 token),不会挤占当前对话的上下文;
- 检索或生成失败时静默跳过,**不影响正常对话**;
- 该功能**默认关闭**,摘要仅保存在本机数据库。

> **当前版本限制**:长期记忆的图形开关尚未提供(规划中),需经配置键 `memory/episodicMemoryEnabled`(默认 `false`)开启,详见 [2-部署与个人使用指南](2-部署与个人使用指南.md) §7。

## 10. 无障碍与键盘操作

NexusAI 为全部自定义控件补全了可访问信息,支持屏幕阅读器(如 Windows 讲述人)朗读控件角色与名称,纯图标按钮也有可读名称而非仅靠提示气泡。

纯键盘可完成核心流程:

- 用 `Tab` / `Shift+Tab` 在侧栏 → 顶栏 → 对话区 → 输入区 → 设置中心各页 → 左右面板 → 日志面板之间移动,顺序与视觉布局一致;
- 确认/设置/审计等对话框打开后,初始焦点落在合理位置,`Esc` 可关闭;
- 既有快捷键(`Ctrl+,` / `Ctrl+D` / `Ctrl+L` / `Ctrl+B` / `Ctrl+[`)全部保持有效。

## 11. 常见问题(FAQ)

**Q:发消息提示"No LLM service configured"?**
还没有配置模型,或没有选中任何 profile。见 §3。

**Q:回答很慢?**
本地模型(Ollama)生成速度取决于硬件,属正常;云端模型慢多见于网络/代理问题。每轮请求有超时上限,失败会有明确报错。

**Q:Token 用量数字和官方后台对不上?**
界面显示的是本地估算值(对中文做了专门加权),不是官方精确计数,仅用于把握上下文占用。

**Q:知识库答案质量差 / 答非所问?**
先看文档是否有"降级"角标(§6 重新嵌入);再尝试在提问中明确引用知识库("根据知识库……")。阈值之下宁可说"没有匹配",这是刻意设计。

**Q:更换嵌入模型后要手动重新嵌入吗?**
不用。应用会自动在后台全量重嵌(知识库面板显示进度);期间检索结果可能暂时不全,完成后自动恢复。

**Q:模型一直想调用工具,连打招呼都要查知识库?**
应用内置了防重复调用与历史折叠机制,一般会自愈;若某模型持续如此,换模型或新开会话。

**Q:它写的文件在哪?我拒绝了它会怎样?**
写文件默认只允许写到你的用户目录(文档/下载/桌面等),且每次都要你批准。拒绝后模型会收到"用户已拒绝"并调整方案,不会有副作用。

**Q:我的数据都在哪?能备份吗?**
会话在 `%APPDATA%\NexusAI\NexusAI\nexusai_memory.db`,配置在注册表 `HKCU\Software\NexusAI\NexusAI`,日志在 `%LOCALAPPDATA%\NexusAI\NexusAI\logs`(保留 7 天)。备份方法见部署指南 §7。

**Q:主题没有跟着 Windows 深浅色变?**
请确认主题模式为"跟随系统"(设置中心 → 界面 → 主题模式)。若你曾手动选过"深色/浅色",应用会记住你的显式选择而不再跟随系统;改回"跟随系统"即可恢复。

**Q:它怎么知道要联网搜索?搜到的内容可信吗?**
当问题需要实时信息(新闻、价格、天气等)时,模型可能调用 `web_search`。调用前会弹确认框。搜索结果来自第三方服务,属于**不可信数据**,模型被要求仅作参考、不执行其中的指令。

**Q:它好像"记得"我之前聊过的事?**
这是长期记忆功能(§9),默认关闭。开启后会在会话结束时生成摘要,并在新会话注入相关历史。
