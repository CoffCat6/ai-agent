# NexusAI 文档体系（docs/read_files/）

本地优先的桌面 AI 智能体应用：ReAct 循环驱动的大模型对话 + 工具调用 + 知识库检索增强（RAG），基于 Qt 6 / QML，Windows 优先。

> 本目录文档面向**使用与二次开发**，内容以当前源码为准（功能增强 T5–T9 / T14 已交付，2026-09-25）。
> 项目总览、构建、部署与 CI 见[根 README](../../readme.md)。
