# AI 应用界面开发完全指南
**文档版本**：V3.0 (Final)
**技术栈**：Qt 6.7+ / QML / C++20 / MVVM
**设计风格**：科技简约风 (支持 暗黑/浅色 双主题动态切换)
**核心目标**：构建高性能、状态可视化、主题可切换的本地智能体桌面应用界面。
---
## 1. 设计理念与视觉基调
NexusAI 的界面设计旨在消除冗余装饰，通过**高对比度、细线分割、状态色点缀**来呈现专业、极客且高效的桌面端体验。界面需原生适应亮暗双主题，以应对不同工作环境。
### 1.1 双主题色彩系统
| 色彩角色 | 暗黑模式 (HEX) | 浅色模式 (HEX) | 应用场景 |
|---------|------------|------------|---------|
| **背景-主** | `#0A0A0F` | `#F5F7FA` | 应用主背景，对话区背景 |
| **背景-次** | `#13131A` | `#FFFFFF` | 侧边栏、输入框、气泡、面板背景 |
| **表面-悬浮** | `#1C1C26` | `#EBEDF0` | 鼠标悬浮、弹窗遮罩内层 |
| **边框-细线** | `#2A2A3A` | `#E5E8EB` | 1px 细线分割，组件边界 |
| **文字-主** | `#E4E4ED` | `#1F2329` | 标题、主要内容 |
| **文字-次** | `#8A8A9F` | `#8F959E` | 时间戳、辅助提示、参数说明 |
| **品牌-主色** | `#00F0FF` (电光青) | `#0052D9` (科技蓝) | 发送按钮、思考中状态、聚焦边框 |
| **状态-成功** | `#00FF94` (矩阵绿) | `#00A870` (翡翠绿) | 工具执行成功、RAG索引完成 |
| **状态-警告** | `#FFB800` (琥珀黄) | `#ED7B2F` (警示橙) | 等待用户确认工具、Token超限 |
| **状态-危险** | `#FF3B30` (赤焰红) | `#F5222D` (警告红) | 工具执行失败、网络错误 |
### 1.2 排版与字体
保持亮暗一致：
- **等宽字体**：`JetBrains Mono` 或 `Cascadia Code`（用于工具调用参数、JSON展示、代码块）。
- **无衬线字体**：`Inter` 或 `思源黑体`（用于 UI 文本与对话内容）。
- **字号层级**：H1 (20px, Bold), H2 (16px, Medium), Body (14px, Regular), Caption (12px, Light)。
### 1.3 动效与特效规范
- **暗黑模式特有**：呼吸发光效果（如思考中的状态点、聚焦的输入框边缘带微光阴影 `DropShadow`）。
- **浅色模式特有**：取消发光，改用轻微的阴影提升层次（如 `DropShadow { color: #10000000; radius: 4 }`）。
- **通用动效**：流式打字光标 `▌` 闪烁；工具调用细节面板以 200ms 的高度动画平滑展开。

## 2. 主题架构与 C++ 交互
主题系统通过 C++ 持久化用户配置，通过 QML 单例全局分发色彩变量。
### 2.1 C++ 端：ThemeManager
```cpp
// src/viewmodels/ThemeManager.h
#pragma once
#include <QObject>
class ThemeManager : public QObject {
    Q_OBJECT
    Q_PROPERTY(bool isDark READ isDark WRITE setIsDark NOTIFY themeChanged FINAL)
private:
    bool m_isDark{true};
    void loadTheme() { /* 从 SQLite 或 QSettings 读取 */ }
    void saveTheme(bool dark) { /* 持久化保存 */ }
public:
    explicit ThemeManager(QObject* parent = nullptr) : QObject(parent) { loadTheme(); }
    bool isDark() const { return m_isDark; }
    void setIsDark(bool dark) {
        if (m_isDark == dark) return;
        m_isDark = dark;
        saveTheme(dark);
        emit themeChanged();
    }
signals:
    void themeChanged();
};
```
### 2.2 QML 端：Theme 单例
在 `qmldir` 中注册为单例，动态绑定 C++ 属性。
```qml
// src/ui/Theme.qml
pragma Singleton
import QtQuick 3.0
import NexusAI.ViewModels 1.0
QtObject {
    readonly property bool isDark: ThemeManager.isDark
    readonly property color bgPrimary: isDark ? "#0A0A0F" : "#F5F7FA"
    readonly property color bgSecondary: isDark ? "#13131A" : "#FFFFFF"
    readonly property color surfaceHover: isDark ? "#1C1C26" : "#EBEDF0"
    readonly property color borderSubtle: isDark ? "#2A2A3A" : "#E5E8EB"
    
    readonly property color textPrimary: isDark ? "#E4E4ED" : "#1F2329"
    readonly property color textSecondary: isDark ? "#8A8A9F" : "#8F959E"
    
    readonly property color brandPrimary: isDark ? "#00F0FF" : "#0052D9"
    readonly property color statusSuccess: isDark ? "#00FF94" : "#00A870"
    readonly property color statusWarning: isDark ? "#FFB800" : "#ED7B2F"
    readonly property color statusDanger: isDark ? "#FF3B30" : "#F5222D"
    // 阴影配置 (浅色模式启用)
    readonly property int elevationRadius: isDark ? 0 : 4
    readonly property color elevationColor: isDark ? "transparent" : "#10000000"
}
```

## 5. 主题适配与无障碍规范
1. **对比度合规**：确保文字与背景的对比度符合 WCAG AA 标准。特别是浅色模式下的次要文字 `#8F959E` 在 `#F5F7FA` 上需保证可读性。
2. **避免纯黑纯白**：暗黑模式背景不用纯 `#000000`，浅色模式大面积背景不用纯 `#FFFFFF`。
3. **图标处理**：
   - 统一使用 SVG 格式。
   - **禁止在 SVG 中硬编码颜色**，使用 `currentColor` 或 `fill="none" stroke="currentColor"`。
   - QML 中通过 `Icon { color: Theme.textSecondary }` 动态控制图标颜色。
4. **代码块语法高亮**：Agent 返回的代码需自带亮暗语法高亮配置，根据 `Theme.isDark` 切换主题（如暗色用 Dracula，亮色用 GitHub Light）。

## 6. 性能优化指南
由于界面涉及大量流式文本与动画，需注意 QML 渲染性能：
1. **文本渲染**：长文本使用 `Text { renderType: Text.NativeRendering }` 提升 CPU 渲染效率，避免 GPU 纹理过大导致卡顿。
2. **流式更新优化**：AgentVM 在追加 token 时，避免每帧触发全量 `layoutChanged`，应使用 `emit traceChanged()` 仅更新最后一个节点的数据。
3. **图层缓存**：固定不变的侧边栏使用 `layer.enabled: true` 缓存为纹理，减少每帧重绘开销。
4. **动画隔离**：呼吸动画仅作用于状态点本身，不要挂载在包含大段文本的父节点上，防止触发整个 Delegate 的重绘。
