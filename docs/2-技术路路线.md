# 本地智能 Agent 应用架构与开发规范文档
**项目代号：NexusAI**
**核心技术栈：C++20 / Qt 6.7+ / QML / SQLite**
**目标定位：** 跨平台、具备本地知识库、支持工具调用与安全沙箱的智能代理桌面应用。
---
## 1. 项目概述与核心能力
将 AI Agent 内核从原应用中剥离，构建独立的桌面智能体应用。核心能力包括：
1. **事件驱动的状态机内核**：告别回调地狱，支持暂停、恢复、取消。
2. **多模型混合路由**：本地小模型做意图识别，云端大模型做深度推理。
3. **三层记忆系统**：短期任务记忆 + 长期 episodic 记忆 + RAG 语义记忆。
4. **安全沙箱与审计**：工具分级权限控制、并发执行配额、全量操作审计日志。
5. **思考链可视化**：QML 实时渲染 Agent 的“思考-工具调用-总结”全过程。
---
## 2. 技术路线选型
| 领域 | 技术选型 | 选型理由 |
|------|---------|---------|
| **语言标准** | C++20 | 必须。使用 `std::coroutine` 消除异步回调地狱，重构 Agent 主循环 |
| **核心框架** | Qt 6.7+ | 原生支持 C++20 协程与事件循环结合；QML 适合动态渲染 Agent 轨迹 |
| **异步库** | QCoro | 封装 Qt 的 QNetworkReply、QFuture 为可 `co_await` 的对象 |
| **本地存储** | SQLite + FTS5 | 零依赖；单文件存储记忆、审计日志、向量数据（BLOB）与全文索引 |
| **向量检索** | Ollama API | 零依赖方案。调用本地 Ollama 的 `/api/embeddings`，无需引入 FAISS |
| **并发执行** | QtConcurrent | 工具池并发执行，避免阻塞 Qt 主线程 |
| **构建系统** | CMake 3.24+ | 支持 C++20 modules（可选），现代 CMake target 链接 |

## 4. 核心模块设计规范
### 4.1 Agent 状态机与协程
**设计原则**：状态机保证 Agent 的生命周期可控；协程保证代码可读性。
```cpp
// src/core/agent/AgentState.h
enum class AgentState {
    Idle, Thinking, AwaitingToolConfirm, 
    ExecutingTool, Summarizing, Completed, Error
};
// src/core/agent/AIAgent.cpp
Task<QString> AIAgent::runImpl(QString userMessage) {
    m_state = AgentState::Thinking;
    emit stateChanged();
    
    while (m_iteration < m_maxIterations) {
        // 1. 调用 LLM (协程化，不阻塞)
        auto response = co_await m_llmService->chatCompleteAsync(m_messages);
        
        // 2. 判断是否需要调用工具
        if (response.toolCalls.empty()) {
            m_state = AgentState::Summarizing;
            co_return response.content; // 最终回复
        }
        
        // 3. 执行工具（带沙箱校验与用户确认）
        for (const auto& call : response.toolCalls) {
            if (requiresConfirmation(call)) {
                m_state = AgentState::AwaitingToolConfirm;
                emit toolConfirmRequired(call.id, call.name, call.args);
                // 挂起协程，等待 UI 点击确认
                bool approved = co_await waitForUserApproval(call.id);
                if (!approved) continue; 
            }
            
            m_state = AgentState::ExecutingTool;
            auto result = co_await m_toolExecutor->executeAsync(call);
            appendToolResult(call.id, result.output);
        }
        m_iteration++;
    }
    co_return "Max iterations reached.";
}
```
### 4.2 记忆与 Token 预算管理
由于长任务会导致对话历史超出 Context Window，必须引入动态压缩。
```cpp
// src/core/memory/SqliteMemory.cpp
QJsonArray SqliteMemory::compressIfTooLong(const QJsonArray& messages, int maxTokens) {
    int currentTokens = estimateTokens(messages);
    if (currentTokens <= maxTokens) return messages;
    
    QJsonArray compressed;
    // 1. 保留 System Prompt
    compressed.append(messages.first()); 
    
    // 2. 将中间旧消息打包，调用小模型生成摘要
    QJsonArray oldMsgs;
    for (int i = 1; i < messages.size() - 10; ++i) oldMsgs.append(messages[i]);
    QString summary = co_await m_llm->summarize(oldMsgs); // 压缩历史
    
    compressed.append(createSystemMsg("Previous conversation summary: " + summary));
    
    // 3. 保留最近 10 条最新消息
    for (int i = messages.size() - 10; i < messages.size(); ++i)
        compressed.append(messages[i]);
        
    return compressed;
}
```
### 4.3 工具沙箱与并发执行
**设计原则**：C++ 层面强制校验，QML 层面引导确认。
```cpp
// src/core/tools/Sandbox.h
class Sandbox {
    bool validatePath(const QString& path, AccessMode mode) {
        QString docDir = QStandardPaths::writableLocation(QStandardPaths::DocumentsLocation);
        // 严禁写入系统目录
        if (mode == Write && !path.startsWith(docDir)) return false;
        return true;
    }
};
// src/core/tools/ToolExecutor.cpp
Task<ToolResult> executeAsync(const ToolCall& call) {
    // 并发执行多个独立工具
    auto result = co_await QtConcurrent::run([call]() {
        auto tool = ToolRegistry::find(call.name);
        if (!tool) return ToolResult::fail("Tool not found");
        
        // 沙箱拦截
        if (!Sandbox::validate(call, tool->definition())) {
            return ToolResult::fail("Blocked by sandbox");
        }
        
        return tool->execute(call.arguments);
    });
    co_return result;
}
```

## 5. QML 与 UI 架构设计
### 5.1 MVVM 绑定原则
**禁止在 QML 中编写业务逻辑**。QML 仅负责数据渲染与捕获用户交互。
```cpp
// src/viewmodels/AgentViewModel.h
class AgentViewModel : public QObject {
    Q_OBJECT
    Q_PROPERTY(AgentState state READ state NOTIFY stateChanged)
    Q_PROPERTY(QString finalResponse READ finalResponse NOTIFY responseReady)
    Q_PROPERTY(QJsonArray traceModel READ traceModel NOTIFY traceChanged)
    
    // 暴露给 QML 的动作
    Q_INVOKABLE void startTask(const QString& input);
    Q_INVOKABLE void approveToolCall(const QString& id, bool approved);
    Q_INVOKABLE void cancel();
};
```
### 5.2 思考链可视化设计
使用 `ListView` 渲染 `traceModel`，根据节点类型动态加载不同的 `delegate`。
```qml

        }
```

## 6. 开发规范
### 6.1 C++ 编码规范
1. **标准**：强制使用 C++20。合理使用 `std::span`, `std::format`, concepts。
2. **内存管理**：全面使用 `std::unique_ptr` / `std::shared_ptr`。Qt 对象继续使用 `QObject` 树管理。禁止裸 `new` 和裸 `delete`。
3. **错误处理**：核心领域层不使用异常（`throw`），统一返回 `Result<T>` 或 `std::expected`（C++23 或自实现）。仅在解析外部不可信数据（如网络 JSON）时使用 `try/catch`。
4. **命名规范**：
   - 类名：`PascalCase` (如 `AgentViewModel`)
   - 变量/函数：`camelCase` (如 `executeToolAsync`)
   - 成员变量：`m_` 前缀 (如 `m_state`)
   - 信号：`sig` 前缀或直接动词 (如 `stateChanged`)
5. **协程使用**：所有涉及网络、文件 IO、工具执行的方法必须返回 `Task<T>`，并在内部使用 `co_await`。
### 6.2 QML 编码规范
1. **属性声明**：使用 `required property` 代替普通 `property`，强制外部注入。
2. **逻辑隔离**：QML 文件中不准出现循环、复杂数据处理逻辑；只能调用 `viewModel.xxx()`。
3. **组件化**：单行超过 300 行的 QML 必须拆分为独立组件。
4. **内存防泄漏**：动态创建的组件必须指定 `parent` 或手动 `destroy()`。
### 6.3 安全与权限规范
1. **工具分级**：
   - 绿色（只读）：直接执行。
   - 黄色（修改本地/网络请求）：必须触发 `toolConfirmRequired` 信号，等待用户在 QML 端确认。
   - 红色（危险命令）：C++ 层直接拒绝，不透出给 LLM。
2. **API Key 保护**：禁止硬编码，从系统环境变量或加密的 SQLite 表中读取。
### 6.4 测试规范
1. **核心层测试覆盖率**：`core/` 与 `infrastructure/` 测试覆盖率不得低于 80%。
2. **Mock 策略**：编写 `MockLLMService` 返回固定 JSON，验证状态机的所有流转路径（包括用户拒绝工具、LLM 返回畸形 JSON 等边界情况）。
3. **QML 测试**：使用 `QtQuickTest` 模块对关键 UI 状态进行截图测试与交互测试。

## 7. 构建与部署
### 7.1 CMake 组织
采用现代 CMake target-based 模式，确保模块解耦。
```cmake
# 核心引擎库（纯 C++，无 Qt UI 依赖）
add_library(nexus_core STATIC)
target_sources(nexus_core PRIVATE
    agent/AIAgent.cpp
    memory/SqliteMemory.cpp
    tools/ToolRegistry.cpp
)
target_link_libraries(nexus_core PUBLIC Qt6::Core Qt6::Sql Qt6::Concurrent)
# 基础设施层
add_library(nexus_infra STATIC)
target_link_libraries(nexus_infra PUBLIC nexus_core Qt6::Network)
# 可执行文件
add_executable(nexus_ai main.cpp)
target_link_libraries(nexus_ai PRIVATE nexus_core nexus_infra Qt6::Quick)
```
### 7.2 依赖管理
- 使用 `vcpkg` 或 `conan` 管理第三方库（如可选用的 `nlohmann/json`、`spdlog`）。
- Qt 建议静态编译或使用官方在线安装程序，确保各平台环境一致。
