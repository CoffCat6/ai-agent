# 47 - 高分屏窗口缩放流畅度与混合 DPI 几何修复

| | |
|---|---|
| **状态** | 已实施（2026-11-09）：test_chat_workflows / test_mention / test_viewmodel / test_agent / qmllint 全绿 |
| **环境** | 3.2K 主屏 @175% 缩放（DPR 1.75）+ 双 1080p 副屏，D3D11 RHI |

## 1. 结论先行

高分屏下拖动缩放卡顿是**两层独立问题叠加**，修复手段完全不同：

| 层 | 症状 | 定位 | 修复 |
|---|---|---|---|
| **布局层**（CPU） | 缩放中内容区周期性掉帧 | 非虚拟化消息列每个 WM_SIZE 步全量重排 MarkdownText | 冻结策略（§3） |
| **渲染层**（GPU/系统） | 窗口边缘追不上鼠标、光标延迟 | 每步全帧重新光栅化（~5.9M 物理像素 × 2~3 overdraw）+ DWM 表面重分配 + swapchain 重建 | **系统开关**（§5），应用内不可根治 |

诊断的关键分岔点：关闭 Windows"拖动时显示窗口内容"后卡顿完全消失 → 瓶颈确系每步渲染的
系统级成本，应用内任何策略只能缓解不能消除。

## 2. 几何 DPI 修复（🐛）

**症状**：启动日志 `setGeometry: Unable to set geometry 1201x800 → 1575x1050`（因子
×1.3125 ≠ DPR 1.75），flaky 测试 winW=686 = 1201/1.75 同源。

**根因**：QML 在 `Component.onCompleted` 极早期以逻辑坐标赋值，原生窗口尚未完成 DPI
归属，Qt 用错误因子做逻辑→原生换算；逻辑值持久化本身也随屏幕 DPR 漂移。

**修复**：
- 几何按**物理像素**持久化（保存 逻辑×DPR，恢复 物理÷目标屏DPR）——缩放比例/屏幕
  变化后恢复的物理尺寸恒定（`AgentViewModel::loadWindowGeometry/saveWindowGeometry`）
- 标记键 `ui/windowPhysX` 必须注册进 SettingsSchema——`writeBatch` 对未注册键**整批
  拒绝**，漏注册会把整个几何写入静默废掉（第一轮验证踩坑）
- 恢复赋值推迟到 `Qt.callLater`（`main.qml`），等窗口完成平台归属

**验证**：恢复后 `actual 1169×813` 与落盘物理值 ÷1.75 精确一致。

**残留告警的真相**：`2100x1400 → 2092x1375` 差 8px = Windows 框架边距收缩，是首帧
默认尺寸提交的 Qt 诊断噪音（任何机器都有），非 DPI 错误，勿再追查。

## 3. 布局冻结策略（⚡）

非虚拟化消息列（TranscriptViewport 头注释的刻意取舍）+ 全宽草稿 TextArea 是仅有的
两个逐宽度重排源。策略（两处同款）：

- 缩放进行中**宽度完全冻结**（变窄 clip 裁边、变宽留白，无错误布局）
- 长拖 >250ms 每 250ms 贴合一次（防留白无限扩大，单次重排稀释到 4Hz）
- 停止 80ms 后一次性贴合，恢复逐像素跟随
- 首帧不节流（delegate 必须以正确宽度创建）
- 常态路径零开销（绑定直连）

**实测教训**：50ms 节拍只是把"每像素重排"降为"每 50ms 重排"，单次全列重排本身
50~200ms，拖动中仍周期掉帧——冻结把不可避免的昂贵重排挪到松手之后。

**刻意不做宽度渐变动画**：`Behavior on width` 会把一次重排摊成每帧重排，恰是最贵
路径；VSCode/Chrome 同为滞后贴合。

顺带修复：`syncPosition` 拆分几何/模型驱动，几何路径不再 forceLayout（会把节流期间
积压的 TextEdit polish 重排提前同步执行打穿节拍）；输入区 `implicitHeight` 在冻结
期间稳定，不再逐帧抖动。

## 4. 诊断基建（已常驻）

- 启动日志 `render: backend=<api> screens [...]`（main.cpp）——后端与每屏 DPR 排查基线
- RHI 后端钉 D3D11（防静默 software 回退；`QT_QUICK_BACKEND` 存在时让位保护测试）

## 5. 用户侧根治手段（写入 README）

Windows"性能选项 → 显示窗口内容的同时拖动"关闭后，缩放只画边框轮廓、松手画内容
——系统级绕开每步渲染，立即根治。影响全局（所有应用），由用户自行取舍。
